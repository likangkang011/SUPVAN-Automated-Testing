## 目录结构说明
| 目录名       | 核心作用                     |
|--------------|------------------------------|
| `config/`    | 项目配置中心（设备、定位、环境） |
| `page_objects/` | 页面对象封装（POM 核心）     |
| `testcases/` | 测试用例集（按功能模块划分）   |
| `utils/`     | 通用工具类（驱动、日志、断言） |
| `data/`      | 测试数据存储（JSON/Excel）    |
| `logs/`      | 自动生成的测试日志           |
| `reports/`   | 自动生成的测试报告（HTML）    |
